Página de carrinho

Agora vamos adicionar a página do carrinho, para isso vamos criar um "module",
no pront de comando escreva: ng g module carrinho --route carrinho --module app.module,
já vai criar um module "carrinho", e sua rota no app.module.

Vai dentro dele no componente carrinho.component.html, e adiciona;
"h2" classe = 'car-title', coloca o nome "Carrinho", fecha o "h2".
"div", dentro da div,
"ul", dentro dela ,
"li", dentro dela,
"img src " coloque uma imagem qualquer só para testar
"p" você coloca "Preço: R$ 300,00", feche a tag.
"label" sem for, dentro dela escreva: "Quantidade:", e dentro dela terá um input
"input" que será do tipo "number",
"/label", fecha a label ,depois da label, coloque:
"button", class="remove-button", dentro desse button, adicione um iconi, aquele de "x",
"i", nome do iconi = "class= fa-solid fa-xmark", feche o "/i",
que é pra dizer que vai exlcuir o produto do carrinho.
"/button", feche o button.
"/li" fecha a tag li,
"/ul" fecha o ul,
"h2" class = "cart-total", depois escreva "Total: R$ 230,00", feche a tag "/h2".
"button", class = "remove-button", escreva "Comprar", "/div" fecha a div.
